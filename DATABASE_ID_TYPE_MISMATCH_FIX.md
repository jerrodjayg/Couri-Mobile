# Database ID Type Mismatch Fix 🎯

## 🚨 **Problem Identified**

The app was throwing a database error when trying to save user data to the `users` table:

```
ERROR ❌ Error saving to users table: {"code": "22P02", "details": null, "hint": null, "message": "invalid input syntax for type bigint: \"71b7e1b6-9983-4e74-a5eb-f9b6b220dc6f\""}
ERROR ❌ Data type error detected - likely ID field type mismatch
```

## 🔍 **Root Cause**

The issue was a **data type mismatch** between the user ID and the database field type:

1. **Supabase Auth User ID**: UUID string (e.g., `71b7e1b6-9983-4e74-a5eb-f9b6b220dc6f`)
2. **Database `users` Table ID Field**: `bigint` (integer) type
3. **Code Issue**: The app was trying to use the UUID string as the `id` field value

## 🔧 **Fix Applied**

### **1. Removed ID Field from Database Insert**
**Before (Broken):**
```javascript
const userDataForUsersTable = {
  id: userId || 'temp_user',  // ❌ UUID string being sent to bigint field
  email: userFromParams.email,
  // ... other fields
};
```

**After (Fixed):**
```javascript
const userDataForUsersTable = {
  // Don't include 'id' field - let database auto-generate it
  // Store the Supabase Auth UUID in auth_user_id field for reference
  auth_user_id: userId || null,  // ✅ UUID stored in proper field
  email: userFromParams.email,
  // ... other fields
};
```

### **2. Changed Conflict Resolution Field**
**Before (Broken):**
```javascript
.upsert(userDataForUsersTable, {
  onConflict: 'id'  // ❌ Trying to resolve conflicts on ID field
});
```

**After (Fixed):**
```javascript
.upsert(userDataForUsersTable, {
  onConflict: 'email'  // ✅ Use email for conflict resolution
});
```

### **3. Added Auth User ID Field**
The Supabase Auth UUID is now stored in the `auth_user_id` field for reference:
```javascript
auth_user_id: userId || null,  // Stores the Supabase Auth UUID
```

## 🚀 **Technical Details**

### **Database Schema Requirements**

The `users` table should have this structure:
```sql
CREATE TABLE users (
  id BIGSERIAL PRIMARY KEY,           -- Auto-incrementing integer
  auth_user_id UUID,                  -- Supabase Auth user ID (nullable)
  email VARCHAR UNIQUE NOT NULL,      -- User email (unique constraint)
  first_name VARCHAR,
  last_name VARCHAR,
  -- ... other fields
);
```

### **Data Flow**

```javascript
Google OAuth Success
  ↓
Extract Supabase Auth UUID
  ↓
Prepare user data WITHOUT 'id' field
  ↓
Include auth_user_id field with UUID
  ↓
Upsert to database using email conflict resolution
  ↓
Database auto-generates integer ID
  ↓
User data saved successfully
```

### **Conflict Resolution Strategy**

- **Primary Key**: `id` (auto-generated by database)
- **Conflict Resolution**: `email` (unique constraint)
- **Auth Reference**: `auth_user_id` (stores Supabase Auth UUID)
